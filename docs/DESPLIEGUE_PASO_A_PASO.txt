PASO 7. PUBLICAR LA API EN EL PUERTO 80 CON NGINX  [VM]
---------------------------------------------------------------------
# Respaldo de la configuración actual
sudo cp /etc/nginx/sites-available/forja /etc/nginx/sites-available/forja.bak

# Insertar el bloque /api/ antes de "location / {" (solo si no existe ya)
grep -q "location ^~ /api/" /etc/nginx/sites-available/forja || sudo sed -i '/^    location \/ {/i\    location ^~ /api/ {\n        proxy_pass http://127.0.0.1:3000;\n        proxy_http_version 1.1;\n        proxy_set_header Host $host;\n        proxy_set_header X-Real-IP $remote_addr;\n        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;\n        proxy_set_header X-Forwarded-Proto $scheme;\n    }\n' /etc/nginx/sites-available/forja

# Revisar que quedó bien
sudo grep -n -A8 "location ^~ /api/" /etc/nginx/sites-available/forja

sudo nginx -t                    # debe decir "syntax is ok" y "test is successful"
sudo systemctl reload nginx

# Si nginx -t marca error, regresar al respaldo:
#   sudo cp /etc/nginx/sites-available/forja.bak /etc/nginx/sites-available/forja
#   sudo nginx -t && sudo systemctl reload nginx

# Comprobar las DOS aplicaciones:
curl -i http://localhost/api/v1/productos | head -n 15     # API -> HTTP/1.1 200 OK + JSON
curl -I http://localhost/login                             # Laravel -> HTTP/1.1 200 OK

# No hay que abrir puertos nuevos: el 3000 es interno y el 80 ya estaba abierto.

Ejecutar EN ORDEN la carpeta "Endpoints":
  1. GET  listar           -> 200
  2. GET  por id (1)       -> 200
  3. POST crear            -> 201 (guarda el id creado en producto_nuevo_id)
  4. PUT  actualizar       -> 200
  5. DELETE eliminar       -> 200
Después la carpeta "Pruebas de errores" (400, 404, 409).

CAPTURAS (una por endpoint) donde se vea: método + URL completa,
body JSON (en POST y PUT), código HTTP y respuesta JSON.

Colección para entregar: en Postman, clic derecho en la colección >
Export > Collection v2.1 (o entregar directamente docs/forja-api.postman_collection.json).

---------------------------------------------------------------------
SI ALGO FALLA
---------------------------------------------------------------------
pm2 logs forja-api --lines 50 --nostream     # errores de la API
pm2 restart forja-api
sudo tail -n 30 /var/log/nginx/error.log     # errores de Nginx

- 502 Bad Gateway en /api/...  -> la API no está corriendo: pm2 status / pm2 logs
- "Access denied for user 'app_api'" -> revisar DB_PASSWORD en .env (con comillas) y el Paso 4
- "SELECT command denied ... table 'X'" -> la API intentó usar una tabla sin permiso
- La app Laravel dejó de cargar -> restaurar forja.bak (Paso 7)
